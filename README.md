# IceLuck

Brand-awareness website for **IceLuck**: frozen cocktails in 150 ml popsicle-style packets, 6% ALC, made in Medellín, Colombia.

IceLuck is a **client brand** site built and maintained by **TuskerMind LLC**. IceLuck is **not** a TuskerMind brand.

**Live:** [https://ice-luck.com](https://ice-luck.com) (also [www.ice-luck.com](https://www.ice-luck.com)).

## Rules

- Product and site documentation live in [`docs/`](docs/).
- Changes go through pull requests; do not push straight to `main`.
- Never commit secrets, API tokens, passwords, or raw API payloads.

## What this is

- Awareness only — no selling, cart, or checkout.
- Markets: Colombia and Ecuador.
- Site language: Spanish (`tú`).
- 18+ age gate before content.
- Hosted on **Cloudflare Pages** (project `iceluck`).
